TROUBLESHOOTING
================================================================================

WORKFLOW FAILED?
→ GitHub Repo → Actions → [Failed Workflow] → Check logs for error
→ Common issues: GitHub Secrets missing/wrong, SSH key permissions, VPS unreachable
→ Re-read error message, add missing secret, push again

CONTAINERS NOT RUNNING?
→ ssh root@194.164.151.202
→ cd /opt/suqly
→ docker-compose -f docker-compose.prod.yml logs
→ Look for error messages from backend/frontend
→ Fix .env if secrets are wrong

PORT ALREADY IN USE?
→ ssh root@194.164.151.202
→ netstat -tlnp | grep 3021      # Check who's using port 3021
→ netstat -tlnp | grep :80       # Check who's using port 80
→ Kill process: kill -9 <PID>

DATABASE NOT INITIALIZING?
→ Check SQL migrations in database/migrations/
→ PostgreSQL health check: docker exec suqly-postgres-1 pg_isready -U postgres
→ Restart: docker-compose -f docker-compose.prod.yml down && docker-compose -f docker-compose.prod.yml up -d

NEED TO MANUALLY RESTART?
→ ./deploy.sh restart
→ Or: ssh root@194.164.151.202 'docker-compose -f /opt/suqly/docker-compose.prod.yml restart'

NEED TO CHECK LOGS?
→ ./deploy.sh logs-backend
→ ./deploy.sh logs-frontend
→ Or manual: docker-compose -f /opt/suqly/docker-compose.prod.yml logs
